## 新手必讀

- [裝機前後檢查清單](docs/build-checklist.md) - 本專案原創，從選零件、組裝到開機測試，一步步打勾確認。

## 零件規格資料庫

- [Intel ARK](https://www.intel.com/content/www/us/en/ark.html) - Intel 官方處理器規格查詢，含腳位、核心數、記憶體支援。
- [AMD 產品規格](https://www.amd.com/en/products/specifications.html) - AMD 官方 CPU 與顯示卡規格總表。
- [TechPowerUp GPU Database](https://www.techpowerup.com/gpu-specs/) - 歷代顯示卡規格資料庫，可比較核心、記憶體與功耗。
- [TechPowerUp CPU Database](https://www.techpowerup.com/cpu-specs/) - 處理器規格資料庫，Intel 與 AMD 都有收錄。
- [TechPowerUp SSD Database](https://www.techpowerup.com/ssd-specs/) - 查 SSD 的控制器、快閃記憶體顆粒與有無 DRAM 快取。

## 相容性與配單工具

- [PCPartPicker](https://pcpartpicker.com/) - 選零件時自動檢查相容性與估算功耗，全球最多人用的配單網站。

## 評測媒體

- [TechPowerUp Reviews](https://www.techpowerup.com/review/) - 評測數量多、數據完整，顯示卡評測常被引用。
- [Gamers Nexus](https://gamersnexus.net/) - 以嚴謹的測試方法著稱，散熱與功耗測試特別深入。
- [Tom's Hardware](https://www.tomshardware.com/) - 老牌硬體媒體，CPU 與 GPU 效能天梯圖很實用。
- [Chips and Cheese](https://chipsandcheese.com/) - 深入分析處理器與顯示卡微架構，適合進階玩家。
- [KitGuru](https://www.kitguru.net/) - 英國硬體媒體，評測涵蓋零件、筆電與周邊。
- [ServeTheHome](https://www.servethehome.com/) - 伺服器、NAS 與網通設備評測。
- [XFastest](https://news.xfastest.com/) - 台灣硬體評測與新聞網站。
- [T客邦](https://www.techbang.com/) - 台灣科技媒體，有大量電腦硬體評測與教學。
- [電腦王阿達](https://www.kocpc.com.tw/) - 台灣科技新聞與產品評測。

## 電源供應器

- [Cybenetics](https://www.cybenetics.com/) - 獨立的電源效率與噪音認證機構，報告比 80 PLUS 更詳細。

## 散熱

- [Noctua 相容性中心](https://ncc.noctua.at/) - 查 Noctua 散熱器與主機板、機殼、記憶體的空間相容性，裝不裝得下先查這裡。

## 螢幕

- [RTINGS](https://www.rtings.com/) - 用統一標準實測螢幕、電視的反應時間、色準與亮度。
- [DisplaySpecifications](https://www.displayspecifications.com/) - 螢幕面板與規格資料庫。
- [TestUFO](https://www.testufo.com/) - 線上測試螢幕殘影、更新率與跳幀。

## 檢測與跑分工具

- [CPU-Z](https://www.cpuid.com/softwares/cpu-z.html) - 查看 CPU、主機板與記憶體的詳細資訊。
- [GPU-Z](https://www.techpowerup.com/gpuz/) - 查看顯示卡規格、時脈與感測器數據。
- [HWiNFO](https://www.hwinfo.com/) - 最完整的硬體資訊與溫度、電壓監控工具。
- [HWMonitor](https://www.cpuid.com/softwares/hwmonitor.html) - 輕量的溫度、電壓、風扇轉速監控。
- [CrystalDiskMark](https://crystalmark.info/en/software/crystaldiskmark/) - 硬碟與 SSD 讀寫速度測試。
- [CrystalDiskInfo](https://crystalmark.info/en/software/crystaldiskinfo/) - 查看硬碟健康度與 S.M.A.R.T. 資訊。
- [Cinebench](https://www.maxon.net/en/cinebench) - CPU 渲染效能跑分，單核與多核都能測。
- [3DMark](https://benchmarks.ul.com/3dmark) - 最常用的顯示卡遊戲效能跑分。

## 穩定性與壓力測試

- [OCCT](https://www.ocbase.com/) - CPU、GPU、記憶體與電源的整合壓力測試工具。
- [Prime95](https://www.mersenne.org/download/) - 經典 CPU 燒機測試，用來驗證超頻穩定性。
- [MemTest86](https://www.memtest86.com/) - 開機碟形式的記憶體錯誤檢測。
- [Memtest86+](https://www.memtest.org/) - 開源版本的開機記憶體檢測工具。

## 超頻

- [HWBOT](https://hwbot.org/) - 全球超頻成績排行與社群。
- [Overclock.net](https://www.overclock.net/) - 老牌超頻論壇，記憶體超頻討論特別多。
- [ThrottleStop](https://www.techpowerup.com/download/techpowerup-throttlestop/) - Intel 處理器降壓與降頻監控工具，筆電玩家常用。

## 系統安裝與驅動

- [Ventoy](https://www.ventoy.net/) - 開源開機隨身碟工具，放入多個系統映像檔即可選擇開機。
- [Windows 11 官方下載](https://www.microsoft.com/software-download/windows11) - 微軟官方映像檔與安裝媒體建立工具，請勿從來路不明的網站下載。
- [DDU (Display Driver Uninstaller)](https://www.wagnardsoft.com/) - 徹底移除舊顯示卡驅動，換卡或驅動出問題時使用。
