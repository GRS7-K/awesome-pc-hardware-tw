# 裝機前後檢查清單

> 從選零件、組裝到開機測試，照順序打勾就不容易出錯。規格以各零件的官方說明書為準，本清單只提醒你「該查什麼」。

[← 回到首頁](../README.md)

## 一、買零件前：相容性

- [ ] **CPU 腳位與主機板相符**：例如 AMD AM5、Intel LGA1700、LGA1851，腳位不同就裝不上。
- [ ] **主機板 BIOS 支援這顆 CPU**：到主機板官網的「CPU 支援列表」確認，新 CPU 配舊主機板時可能要先更新 BIOS。
- [ ] **記憶體世代正確**：主機板只支援 DDR4 或 DDR5 其中一種，兩者不能混用。
- [ ] **記憶體在主機板 QVL 名單內**（建議）：QVL 是主機板廠測試過的記憶體清單，可降低不相容機率。
- [ ] **顯示卡長度、厚度放得進機殼**：對照機殼規格頁的「顯示卡長度限制」。
- [ ] **散熱器高度放得進機殼**：塔式散熱器看機殼的「CPU 散熱器高度限制」；水冷看冷排支援的位置與尺寸。
- [ ] **散熱器有對應腳位的扣具**：舊散熱器搭新腳位，可能要另外索取扣具。
- [ ] **主機板尺寸符合機殼**：ATX、Micro-ATX、Mini-ITX。
- [ ] **電源瓦數足夠並保留餘裕**：可用 [PCPartPicker](https://pcpartpicker.com/) 估算整機功耗，再加上餘裕。
- [ ] **電源接頭數量足夠**：特別注意顯示卡需要的 PCIe 8-pin 或 12V-2x6（12VHPWR）接頭。
- [ ] **M.2 插槽數量與共用限制**：部分主機板的 M.2 插槽會和 SATA 埠或 PCIe 插槽共用頻寬，詳見主機板說明書。

## 二、組裝時

- [ ] **先在機殼外試開機**（建議）：只裝 CPU、散熱器、一條記憶體和電源，確認能進 BIOS 再裝進機殼，出問題時好排查。
- [ ] **機殼銅柱位置對應主機板螺絲孔**：多出來的銅柱要拿掉，避免頂到主機板背面造成短路。
- [ ] **CPU 方向正確**：對準 CPU 角落的三角形記號，放下時不要用力壓。
- [ ] **散熱膏與保護膜**：散熱器底座如果有保護膜要撕掉；已預塗散熱膏的就不用再塗。
- [ ] **記憶體插在正確插槽**：兩條時通常插在說明書建議的插槽（多為 A2 與 B2），並且壓到兩邊卡榫扣上。
- [ ] **CPU 供電線（EPS 8-pin）有插**：在主機板左上角，漏插就無法開機。
- [ ] **顯示卡供電線完全插到底**：12V-2x6（12VHPWR）接頭沒插緊可能導致接頭過熱。
- [ ] **前面板線路（開機鍵、指示燈）接對**：位置對照主機板說明書。
- [ ] **螢幕線接在顯示卡上**，不是主機板的輸出孔（有獨立顯示卡時）。

## 三、第一次開機

- [ ] **DDR5 第一次開機可能要等比較久**：主機板會做記憶體訓練，黑畫面幾分鐘是正常的，不要急著重開。
- [ ] **能進 BIOS 後確認**：CPU 型號、記憶體容量與硬碟都有被偵測到。
- [ ] **開啟記憶體 XMP 或 EXPO**：不開的話記憶體會以預設的較低速度運作。
- [ ] **確認 CPU 溫度正常**：在 BIOS 待機時溫度不應持續飆高，否則檢查散熱器是否裝好。

## 四、裝好系統後

- [ ] **從官方管道安裝系統**：[Windows 11 官方下載](https://www.microsoft.com/software-download/windows11)，不要用來路不明的映像檔。
- [ ] **從官網下載驅動程式**：主機板晶片組、顯示卡驅動都到原廠網站下載。
- [ ] **更新 BIOS**（需要時）：只從主機板官網下載，更新過程中不可斷電。
- [ ] **監控溫度**：用 [HWiNFO](https://www.hwinfo.com/) 觀察 CPU 與顯示卡溫度。
- [ ] **壓力測試**：用 [OCCT](https://www.ocbase.com/) 或 [Prime95](https://www.mersenne.org/download/) 跑一段時間，確認不當機、溫度在合理範圍。
- [ ] **記憶體測試**：開了 XMP/EXPO 或自行超頻後，可用 [MemTest86](https://www.memtest86.com/) 或 [Memtest86+](https://www.memtest.org/) 檢查是否有錯誤。
- [ ] **硬碟健康度**：用 [CrystalDiskInfo](https://crystalmark.info/en/software/crystaldiskinfo/) 確認狀態為「良好」。
